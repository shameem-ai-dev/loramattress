Zero Plaintext OTP Storage & Client Isolation

LORA OTP architecture strictly follows zero-trust standards. Real OTP values are cryptographically hashed using SHA-256 before verification comparison and are never written to browser storage, console logs, or audit records. All API secrets are masked (e.g. ••••••••A92F) and only authorized Super Admin users can modify integration parameters.

📍 Two-Tier Studio Matching Engine (Pincode + 40 km Geometric Radius)

When a customer searches on the storefront, the engine first matches against manually assigned serviced pincodes configured below. If no direct pincode match is found, it calculates the geographic distance using the Haversine 40 km radius formula from the store coordinates. If still outside 40 km, the customer is shown the reassuring doorstep delivery message: "We are coming soon to your location — but don’t worry, we will deliver to your doorstep!" and their lead is recorded for follow-up.
